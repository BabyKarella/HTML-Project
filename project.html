Project Portfolio Overview

Developed a machine learning-based web application using Python, Streamlit, and Random Forest to analyze student engagement data and predict performance levels, helping educators identify at-risk students and improve learning outcomes.

1.Data-Driven Student performance Prediction system

▼ Project Details

This Project Predicts student engagements levels based on learning activities such as logins,content reads,assigment submissions,and quiz reviews.

Features
  • Interaction Streamlit dashboard
  • Data visualization using charts and graphs
  • feature importance analysis
  • Real-time Prediction system

Technologies used: Python,Streamlit,pandas,Numpy,Scikit-learn,Matplotlib,seaborn.

Algorithm Used:Random Forest Classifier

Challenges:
